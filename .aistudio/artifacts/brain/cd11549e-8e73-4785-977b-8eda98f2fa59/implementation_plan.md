# AI 프롬프트 모음 (GitHub 배포 및 고도화)

Google Apps Script 기반의 AI 프롬프트 모음 서비스를 정적 호스팅(GitHub Pages / `token-web.github.io`) 및 최신 프론트엔드 웹 앱으로 전환하고, 비밀번호(`868686`) 기반 관리자 모드(추가/수정/삭제/데이터 내보내기·가져오기), 반응형 비포/애프터 비교 슬라이더 및 큐레이션된 고품질 샘플 이미지, 한글 및 영문 듀얼 프롬프트 탭 및 원클릭 복사 시스템을 구축합니다.

### User Review & Critical Decisions

> [!IMPORTANT]
> 사용자가 확정한 3가지 주요 결정 사항을 기반으로 구현을 진행합니다.

- **GitHub 배포 및 영속성 방식 (사용자 ID: `token-web`)**:
  - `token-web.github.io` 및 GitHub 저장소 환경에서 완벽하게 동작하도록 정적 호스팅 친화적 아키텍처로 구현합니다.
  - 기본 내장 프롬프트 데이터셋(JSON) + 브라우저 변경사항 영속화(`localStorage`) + 관리자 전용 **[JSON 내보내기/가져오기]** 기능을 제공하여, 관리자가 수정한 데이터를 JSON 파일로 다운로드하여 GitHub 저장소에 바로 커밋할 수 있도록 지원합니다.
- **비포/애프터 샘플 사진 방식**:
  - 인물 프로필 스튜디오 연출, 배경 교체 및 누끼 합성, 웹툰/일러스트 스타일 변환, 3D 제품 렌더링 등 대표적인 생성형 AI 활용 사례를 선별하여 고품질 큐레이션 비포/애프터 샘플 세트를 기본 내장합니다.
  - 마우스 드래그 및 터치로 조작 가능한 인터랙티브 분할 슬라이더(Split-Slider)를 구현합니다.
- **한글 및 영문 프롬프트 제공 방식**:
  - 각 프롬프트 상세 모달 내에 `[한글]` / `[English]` 탭 토글을 배치하고, 개별 탭 상태에 맞춘 원클릭 클립보드 복사(Copy) 및 `.txt` 다운로드 기능을 제공합니다.

### 1. Overview & Core Concept

- **What It Does**:
  - 인공지능 이미지 및 텍스트 프롬프트를 카테고리별로 탐색하고, 실시간 검색, 버전별 비교, 비포/애프터 결과 확인, 한글 및 정밀 번역된 영문 프롬프트 원클릭 복사를 제공하는 웹 애플리케이션.
  - 관리자 비밀번호 `868686` 입력을 통해 활성화되는 관리자 모드에서 프롬프트의 실시간 추가, 수정, 삭제, 이미지 업로드, 데이터 동기화 지원.
- **Target Audience / Persona**:
  - AI 이미지(Midjourney, Stable Diffusion, DALL-E, Nano Banana 등) 및 텍스트 모델을 활용하는 학생, 창작자, 연구자 및 일반 사용자.
  - 교육혁신센터 정한열 교수(AI Insight Lab)의 강의 수강생 및 커뮤니티 사용자.
- **Key Value**:
  - GAS 서버 종속성 없이 GitHub Pages에서 무제한 무료 서빙 가능.
  - 한글과 영문 프롬프트를 모두 지원하여 글로벌 AI 툴과의 호환성 극대화.
  - 비포/애프터 시각적 예시를 통해 프롬프트 적용 효과를 한눈에 직관적으로 체감.

### 2. User Experience & Visual Design

- **Key User Flows**:
  1. **탐색 & 필터링**: 메인 화면에서 카테고리 카드(인물 사진, 예술/화풍, 제품/상업, 캐릭터/애니, 실무 텍스트 등)를 클릭하여 프롬프트 목록으로 진입하거나 상단 통합 검색창으로 즉시 검색.
  2. **상세 조회 & 듀얼 프롬프트**: 프롬프트 카드 클릭 시 슬라이드업 시트/모달 표시.
     - 비포 & 애프터 슬라이더를 좌우로 드래그하여 원본과 생성 결과 비교.
     - `[한글]` / `[English]` 탭으로 전환하여 언어별 최적화된 프롬프트 본문 확인.
     - `[📋 복사하기]` 클릭 시 현재 선택된 언어 프롬프트가 즉시 클립보드에 복사되며 토스트 알림 표시.
  3. **관리자 모드 (비밀번호: `868686`)**:
     - 하단 또는 헤더의 '관리자' 버튼 클릭 후 비밀번호 입력 (`868686`).
     - 관리자 툴바 노출 (`＋ 프롬프트 추가`, `💾 데이터 내보내기/가져오기`, `로그아웃`).
     - 각 프롬프트 카드/모달에 `✎ 수정`, `🗑 삭제`, `＋ 버전 추가` 버튼 활성화.
     - 편집 모달에서 카테고리, 제목, 한줄설명, 버전명, 유형, 한글 프롬프트, 영문 프롬프트, 비포/애프터 사진 파일 업로드 지원.

- **Visual Identity & Theme**:
  - *Aesthetic Direction*: 신뢰감 있는 딥 네이비(`var(--navy)`, `#0b1f3a`)와 산뜻한 시안 블루(`var(--cy)`, `#22d3ee`), 부드러운 페이퍼 캔버스(`#f3f6fb`)를 바탕으로 한 지식/디렉터리 디자인.
  - *Typography*: 한글 가독성이 뛰어난 산세리프 폰트 스택(`Noto Sans KR`, `Apple SD Gothic Neo`, `system-ui`)과 데이터/영문 프롬프트용 모노스페이스(`JetBrains Mono`, `ui-monospace`).
  - *Component Styling*:
    - Top Bar: 브랜드 워드마크(`AIINSIGHT`), 무료 태그, 외부 연계 링크(`나의 추억 앨범 만들기`), 관리자 토글.
    - Before/After Slider: 둥근 핸들과 구분선, 터치/마우스 드래그 부드러운 전환.
    - Zero-Pill 메타데이터: 카테고리, 버전, 사진 필요 여부 등 정돈된 텍스트 계층 구조.

### 3. Key Product Decisions & Trade-Offs

- **Decision 1: 정적 배포(GitHub Pages) 호환 데이터 아키텍처**
  - *선택*: 빌트인 고품질 프롬프트 JSON + `localStorage` 오버레이 + 관리자 JSON Export/Import.
  - *이유*: GitHub Pages(`token-web.github.io`)는 서버 사이드 DB가 없는 정적 호스팅이므로, 사용자가 서버 비용이나 별도 호스팅(Heroku, Render 등) 없이 깃허브 레포지토리에 푸시만 하면 즉시 전 세계에 서비스될 수 있습니다.
  - *대안 검토*: Node.js Express + SQLite 서버 구성은 별도 유료/무료 PaaS 호스팅 설정이 필요하여 GitHub 단독 배포 목적에 맞지 않음.
- **Decision 2: 한글 & 영문 프롬프트 스키마 확장**
  - *선택*: 프롬프트 버전에 `bodyKo`(한글)와 `bodyEn`(영문), `guideKo`, `guideEn` 필드를 독립적으로 제공.
  - *이유*: 생성형 AI는 영어 토큰 구조에서 훨씬 정밀한 묘사(Cinematic lighting, 8k, volumetric rays 등)가 발휘되므로, 한글 사용자 안내문과 영문 전용 프롬프트를 동시에 제공할 때 실사용 효율이 극대화됨.
- **Decision 3: 비포/애프터 이미지 애셋 처리**
  - *선택*: SVG 및 고해상도 최적화 WebP/Base64/로컬 애셋 기반으로 로딩 오류가 전혀 발생하지 않는 자체 내장 샘플 세트 구성 + 관리자 모드에서 이미지 업로드 시 브라우저 내 IndexedDB/LocalStorage 압축 저장 지원.

- **Data Models**:
  - `PromptGroup`: `id`, `cat`, `title`, `icon`, `tag`, `versions: PromptVersion[]`
  - `PromptVersion`: `id`, `name`, `type` ('이미지 생성' | '텍스트'), `photo`: boolean, `guideKo`: string, `guideEn`: string, `bodyKo`: string, `bodyEn`: string, `beforeImg`: string, `afterImg`: string, `next`: string, `hidden`: boolean
- **Admin Authentication**:
  - 비밀번호: `868686` 검증 후 브라우저 세션 스토리지에 관리자 토큰 설정.
- **Git Sync Feature**:
  - 관리자 모드에서 언제든 `prompts-data.json` 다운로드 가능. 깃허브 레포지토리의 기본 데이터로 커밋하면 모든 방문자에게 최신 버전이 공유됩니다.
